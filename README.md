# Python Expense Tracker

A beginner-friendly Python project that tracks expenses and calculates category-wise totals.

## Features
- Add expenses with category and amount
- Store multiple expense records
- Calculate total expenses for each category
- Simple console-based application

## Technologies Used
- Python 3

## How It Works
The program:
1. Takes expense category input
2. Takes expense amount
3. Stores expenses in a list
4. Calculates category-wise expense totals
5. Displays the final expense summary

## Concepts Used
- Lists
- Dictionaries
- Loops
- Dictionary get() method
- User input handling

```bash
python expense_tracker.py
